# Таблица продуктов

`products.json` — редактируемый источник страницы `/food-table`. Данные не связаны с коллекциями рецептов. При пустом поиске видны все записи, без страниц и кнопок «загрузить ещё».

Начальные 492 строки перенесены из пользовательского PDF `898533057-Low-fodmap-Диета-Таблица.pdf` (10 страниц, получен 2026-11-21). Исходник сохранён как `public/reference/low-fodmap-table.pdf`. Проверены номера 1–492 без пропусков и дублей, названия, группа и положение колонок; все 10 страниц просмотрены после рендеринга. Это перенос источника, а не независимая медицинская верификация его содержания. Исходные спорные значения, опечатки и единицы не исправляются молча.

Каждая запись содержит стабильный `id`, название `name`, группу `group`, три текстовые дозы `safeDose`, `mediumDose`, `highDose` либо объединённое поле `combinedDose`, дополнительные поисковые названия `aliases`, примечание `note` и происхождение `source` (файл, страница, номер строки). Объединённые ячейки не считаются тремя одинаковыми дозами. В PDF 106 таких записей; сохранён `colSpan=3`. В строках 50 и 206 из-за дополнительного микросегмента сетки распалось обозначение последней дозы — оно собрано обратно без изменения значения. Цвета в интерфейсе служат визуальной навигации; точные формулировки источника сохранены.

Для расширения добавьте объект с новым стабильным `id`, дозами и достоверным источником. Новые поисковые синонимы добавляйте в `aliases`. Если группа не известна, используйте `null`, интерфейс покажет «Не указана». Не выдавайте отсутствие данных за «Без ограничений». Изменение исходных значений следует пояснить в `note`, сохраняя происхождение.

`scripts/import-food-table.py <input.pdf> <output.json>` воспроизводит первоначальный импорт через pdfplumber. Не запускать поверх ручных исправлений и дополнений: импорт перезаписывает файл. Для обычных правок Python не нужен. `npm run validate:data` проверяет структуру JSON и поведение поиска. При расширении таблицы исходные строки остаются с прежними идентификаторами, источник новых строк указывается отдельно.

Поиск буквальный по подстроке во всех видимых полях и в `aliases`, без учёта регистра, с эквивалентностью е/ё, нормализацией пробелов и Unicode. Поэтому «рис» находит «рисовые», а «МЕД» также находит «Мёд». Пустая строка и пробелы возвращают всю таблицу. Порядок записей соответствует JSON.
