# Рецепты ma-x.im

Личный статический сайт рецептов с поиском, корзиной блюд и агрегированным списком покупок.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
```

Готовая статика появляется в `out/`.

## Контент

Одобренные рецепты хранятся в `content/approved/*.md`. Перед разработкой и сборкой скрипт `scripts/generate-recipes.mjs` автоматически создаёт типизированный JSON для интерфейса.

При добавлении нового продукта обновите его каноническое имя и магазинную группу в `scripts/generate-recipes.mjs`. Команда `npm run validate:data` проверяет уникальность адресов, время, ингредиенты и шаги.

## Локальные данные

Корзина, количество порций и галочки в покупках сохраняются в `localStorage` браузера. Сервер и база данных не используются.

## GitHub Pages

Сайт публикуется через GitHub Actions из ветки `main`. Workflow выполняет проверки, собирает статические файлы в `out/` и отправляет их в GitHub Pages.

Для первого запуска в репозитории нужно открыть `Settings → Pages` и выбрать `Source: GitHub Actions`. Затем в поле `Custom domain` указать `food.ma-x.im`.

В DNS домена создаётся запись `CNAME`: `food` → `maximusft.github.io`. База данных, сервер и секреты не нужны.
